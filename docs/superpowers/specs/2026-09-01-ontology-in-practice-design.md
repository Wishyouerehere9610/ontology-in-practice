# Ontology in Practice 项目设计

## 目标

把《FDE 必看 Ontology 落地技术细节》视频中的页面和讲解蒸馏成一份可独立阅读的中文长页 HTML，并放入私有 GitHub 仓库 `ontology-in-practice`。这是一份原创重写的实践指南，不是字幕或视频原页的逐字复制。

## 受众与使用场景

- 面向正在做企业 AI、Agent、FDE 和知识工程的读者。
- 读者应能在 10–15 分钟内建立完整框架，并带走可执行的生产落地清单。
- HTML 可直接离线打开，不依赖构建流程、第三方 CDN 或远程字体。

## 内容结构

1. 封面：一句话结论、适用人群、阅读路径。
2. 问题：为什么“把文档直接扔给 LLM”会得到不稳定的业务答案。
3. 定义：Ontology 作为对象、关系、规则、函数、动作和权限的业务操作层。
4. 五种构建路线：拆解流水线、行业框架约束、人机协同、循环自反思和端到端原型。
5. 数据管道：结构化数据、文档/媒体引用、变换管道和增量更新。
6. 操作层：Object、Link、Function、Action 如何把知识图谱变成可执行系统。
7. Agent 交互：Retrieval Context、Object Query、Document Context 和关系追溯的分工。
8. 治理：最小权限、可执行边界、人工确认、审计日志和 MCP 边界。
9. 落地清单：从业务问题到生产验收的六步路径。
10. 来源与方法：视频链接、蒸馏范围、识别误差说明。

## 视觉设计

- 白底、黑字、细线网格，用低饱和蓝和柔和绿区分“数据”与“操作”。
- 桌面端使用左侧粘性导航 + 中央长文；移动端折叠为顶部横向章节导航。
- 用 HTML/CSS 绘制路线对比、管道、操作层和安全边界示意，不将核心知识锁在图片中。
- 页面只保留一个有价值的交互：阅读进度与当前章节高亮。

## 内容边界

- 不收录完整视频字幕。
- 不冒充 Palantir 官方文档，不把讲者举例扩大为产品承诺。
- 对字幕中的 `palenteer`、`red`、`PTF` 等识别错误，按画面与语义修正为 Palantir、RAG、PDF。
- 页尾标明“基于公开视频的学习型蒸馏”并链回原视频。

## 验收

- 页面包含 8 个以上有语义的主章节，导航与章节一一对应。
- 包含五种构建路线、四层操作模型、Context/Query 决策规则、权限与审计边界。
- 小红书原视频链接可见，但页面无小红书媒体热链。
- 1440px 和 390px 视口下无页面级水平溢出，正文可读。
- 禁用远程字体、远程脚本和第三方前端依赖。
